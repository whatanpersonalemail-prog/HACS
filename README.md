# Google Home Local Bridge

Custom Home Assistant integration for HACS.

## Installation

1. Add this repository to HACS as a custom repository.
2. Install `Google Home Local Bridge`.
3. Restart Home Assistant.
4. Go to Settings -> Devices & Services -> Add Integration -> Google Home Local Bridge.
5. Choose Local API or Cloud API and enter credentials.

## Notes

This integration uses a DataUpdateCoordinator and supports climate, sensor, and switch platforms.
